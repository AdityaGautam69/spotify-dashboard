🎧 Spotify Analysis Dashboard – Power BI

This project presents an interactive Spotify Music Insights Dashboard built using Power BI.
The dashboard analyzes popular tracks, artists, albums, and listening trends using the Spotify Global Charts Dataset.

📌 Key Features

✅ Interactive visuals with dynamic filtering
✅ Popularity insights at song, artist & album level
✅ Explicit vs. non-explicit content analysis
✅ Duration analytics (seconds & hours)
✅ Release date and trend analysis
✅ Album type distribution — Singles, Albums & Compilations
✅ Top 10 charting tracks and artist dominance
✅ KPIs built using custom DAX measures

🛠️ Tech Stack
Tool	Purpose
Power BI	Data Modeling & Visualization
DAX Measures	Calculated insights
Spotify Dataset	Source data
📊 DAX Measures Included

Total Songs, Unique Artists & Songs

Popularity Metrics (avg, min, max, trend change)

Explicit Songs %, Recent Releases KPIs

Duration and Album Type breakdowns

Artist frequency & dominance indicators

(All measures are optimized for performance and accuracy.)

🚀 Insights You Can Gain

Which artists consistently rank higher on charts?

Do explicit songs perform better than clean tracks?

How long are the most trending songs?

Are recent releases gaining more popularity?

What album type dominates the charts?

🧩 Interactivity

Users can explore the dataset with:

Slicers for filtering by year, artist, album type, and explicit label

Drill-downs in charts to analyze deeper insights

Dynamic KPI cards updating in real-time
